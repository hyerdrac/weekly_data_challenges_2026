# Weekly Data Challenges 2026

## 📌 Overview

This repository contains my **weekly data projects for the year 2026**. The goal of this repository is to **consistently improve my data skills** by completing **one data-related challenge every week** throughout the year.

Each project focuses on a different problem, dataset, or analytical technique, and is designed as a practical learning exercise rather than a polished end product.

---

## 🎯 Purpose & Motivation

The main objectives of this repository are:

* 📊 To build a **clear and structured data portfolio**
* 🧠 To improve my skills through **continuous, hands-on practice**
* 🔁 To explore different datasets, methods, and analytical perspectives
* 🤝 To share my work so others can **learn from, reuse, or adapt** the ideas

The emphasis is on **learning by doing**, consistency, and long-term improvement.

---

## 🗂 Repository Structure

Projects are organized on a **weekly basis**.

```
weekly_data_challenges_2026/
│
├── week-01/
│   ├── README.md
│   ├── notebooks/
│   ├── outputs/
│   └── notes.md
│
├── week-02/
│   ├── README.md
│   ├── notebooks/
│   ├── outputs/
│   └── notes.md
│
└── ...
```

Each weekly folder typically includes:

* One or more **Jupyter notebooks**
* **Outputs** such as plots, tables, or summary results
* A short **README** explaining the problem, approach, and key findings

> **Note:** The internal structure of each project may vary depending on the nature of the analysis and the tools or technologies used.

Raw datasets are **not included** in this repository. Links to original data sources are provided instead.

---

## 🧪 Project Scope

Depending on the week, projects may involve:

* Exploratory Data Analysis (EDA)
* Data cleaning and preprocessing
* Data visualization and storytelling
* Statistical analysis
* Introductory machine learning models
* Time series or regression analysis

Project complexity may vary from week to week.

---

## 📊 Data Sources

All datasets used in this repository are obtained from **publicly available sources** (e.g., open data portals, research repositories, or competition platforms).

To respect data licensing and redistribution restrictions:

* Raw data files are **not stored** in this repository
* Each project includes a reference or link to the **original data source**

## 🔁 Reproducibility Note

The analyses can be reproduced by downloading the datasets directly from their original sources and running the provided notebooks.

Minor differences in results may occur due to data updates or environment differences.
