# Week 26 – KMeans Cluster Practice


## About the Project

This project focuses on clustering quake events based on their geographical characteristics.

---

## Goal

The goal of this project is to apply the K-Means clustering algorithm to quakes data in order to identify geographical patterns. The optimal number of clusters (K=3) was determined using the Elbow Method and Silhouette Analysis. The K-Means algorithm was then implemented to group earthquake events into three distinct clusters based on their geographical characteristics.

---

## Dataset

* **Source:** [Quakes](https://www.kaggle.com/datasets/mathurinache/quakes/data)
* **Description:**  Dataset from Smoothing Methods in Statistics (ftp stat.cmu.edu/datasets)
Simonoff, J.S. (1996). Smoothing Methods in Statistics. New York: Springer-Verlag.

## What Was Done

- Examined the dataset structure and descriptive statistics to understand the characteristics of the quakes data.
- Performed Exploratory Data Analysis (EDA) to investigate data distributions, relationships, and geographical patterns.
- Determined the optimal number of clusters (K=3) using the Elbow Method and Silhouette Analysis.
- Implemented the K-Means clustering algorithm with three clusters.
- Visualized and evaluated the clustering results to interpret the geographical distribution of earthquake events.
