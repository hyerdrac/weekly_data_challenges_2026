# Week 08 – Churn Analysis Machine Learning Model


## About the Project

The goal of this project is to build a machine learning model for customer churn prediction using a churn analysis dataset. In [week-02](/week-02/), I conducted a churn analysis and explored the concept of data drift. This week, I fully focus on churn prediction models and how to improve their performance.


---

## Goal

- Explore and clean the data to prepare it for churn analysis  
- Build a machine learning model to predict customer churn  
- Optimize model performance through feature engineering

---

## Dataset

* **Source:** [Telco Customer Churn](https://www.kaggle.com/datasets/blastchar/telco-customer-churn/data)
* **Description:**  "Predict behavior to retain customers. You can analyze all relevant customer data and develop focused customer retention programs." [IBM Sample Data Sets] (Based on the original dataset description)

> The raw dataset is not included in this repository. Please refer to the original Kaggle source.

---

## Tools Used

* Python
* pandas
* scikit-learn

---

## What Was Done

- Conducted Exploratory Data Analysis (EDA)  
- Trained and evaluated churn prediction models using Logistic Regression and Random Forest  
- Performed feature selection by removing selected variables  
- Re-trained and compared Logistic Regression and Random Forest models using the reduced feature set  
- Analyzed and compared model performance across different feature configurations
