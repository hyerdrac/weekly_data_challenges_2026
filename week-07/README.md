# Week 07 – Data Cleaning Challenge 2

## About the Project

This week, I revisited and strengthened my data cleaning skills.

This project focuses on systematically performing and explaining the data cleaning process step by step. It highlights common data quality issues encountered in real-world datasets and demonstrates practical solutions to address them.
---

## Goal

The objectives of this project are to:

- Identify and address common data quality issues in a real-world retail store sales dataset
- Clean and standardize key variables such as item names, prices
- Handle missing and inconsistent values based on business logic rather than aggressive deletion
- Reduce unnecessary data loss while preserving the analytical value of the dataset

---

## Dataset

* **Source:** [Retail Store Sales: Dirty for Data Cleaning](https://www.kaggle.com/datasets/ahmedmohamed2003/retail-store-sales-dirty-for-data-cleaning)
* **Description:** The Dirty Retail Store Sales dataset contains 12,575 rows of synthetic data representing sales transactions from a retail store. The dataset includes eight product categories with 25 items per category, each having static prices. It is designed to simulate real-world sales data, including intentional "dirtiness" such as missing or inconsistent values. This dataset is suitable for practicing data cleaning, exploratory data analysis (EDA), and feature engineering. (Based on the original dataset description)

> The raw dataset is not included in this repository.
