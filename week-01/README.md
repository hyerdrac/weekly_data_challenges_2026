# Week 01 – Data Challenge

![](/week-01/images/output_22_0.png)

## About the Project

This is the first project of the **Weekly Data Challenges 2026** series.

The main purpose of this project is to analyze industry roles and salaries and present key insights using visual analysis.

---

## Goal

To analyze roles and salaries in the industry using data from 2020 to 2025 and present the findings through visualizations.


---

## Dataset

* **Source:** [The AI, ML, Data Science Salary (2020- 2025)](https://www.kaggle.com/datasets/samithsachidanandan/the-global-ai-ml-data-science-salary-for-2025)
* **Description:** This Dataset containes the details of the AI, ML, Data Science Salary (2020- 2025). Salary data is in USD and recalculated at its average fx rate during the year for salaries entered in other currencies. (Based on the original dataset description)

> The raw dataset is not included in this repository. Please refer to the original source.
