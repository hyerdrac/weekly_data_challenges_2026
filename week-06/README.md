# Week 06 – Paired Analysis of CO₂ Emissions Using Wilcoxon Signed-Rank Test

## About the Project

Data cleaning and preparation are critical parts of any data science project. In real-life datasets, data is often messy and incomplete.

This project focuses on performing and explaining the data cleaning process step by step.

---

## Goal

The objectives of this project are to:

- Identify and address common data quality issues in a real-world café sales dataset
- Clean and standardize key variables such as item names, prices, and locations
- Handle missing and inconsistent values based on business logic rather than aggressive deletion
- Reduce unnecessary data loss while preserving the analytical value of the dataset

---

## Dataset

* **Source:** [Cafe Sales - Dirty Data for Cleaning Training](https://www.kaggle.com/datasets/ahmedmohamed2003/cafe-sales-dirty-data-for-cleaning-training/data)
* **Description:** The Dirty Cafe Sales dataset contains 10,000 rows of synthetic data representing sales transactions in a cafe. This dataset is intentionally "dirty," with missing values, inconsistent data, and errors introduced to provide a realistic scenario for data cleaning and exploratory data analysis (EDA). It can be used to practice cleaning techniques, data wrangling, and feature engineering. (Based on the original dataset description)

> The raw dataset is not included in this repository.
